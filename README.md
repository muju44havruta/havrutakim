# 세특 작성 도우미

학생이 수행한 결과물을 PDF로 업로드하거나 직접 입력한 자료를 바탕으로, Claude API를 이용해
과목별 세부능력 및 특기사항(세특) 문구 초안을 생성하는 Streamlit 앱입니다.

생성된 문구는 초안입니다. 반드시 교사가 사실관계와 내용을 검토·수정한 후 학교생활기록부에
반영하세요.

## 실행 방법

```bash
pip install -r requirements.txt

# Anthropic API 키를 환경변수로 설정 (또는 앱 실행 후 사이드바에서 직접 입력)
export ANTHROPIC_API_KEY="sk-ant-..."

streamlit run app.py
```

브라우저에서 `http://localhost:8501` 으로 접속하면 됩니다.

## 사용 흐름

1. **자료 입력**: 학생이 수행한 결과물의 PDF를 업로드해 텍스트를 추출하거나, 텍스트를 직접 입력합니다.
   두 방식을 함께 사용할 수 있습니다. (스캔본/이미지 PDF는 텍스트 추출이 되지 않을 수 있습니다.)
2. **학생 정보 및 옵션**: 학생 이름, 과목, 글자수, 문체 등을 선택합니다.
3. **세특 생성**: Claude API를 호출해 세특 문구 초안을 생성합니다.
4. **검토 및 저장**: 생성된 문구를 직접 수정한 뒤 기록으로 저장하거나 텍스트 파일로 다운로드합니다.

저장된 기록은 `data/records.json`에 로컬로 저장되며, '저장된 기록' 메뉴에서 학생별로 조회·수정·삭제할
수 있습니다.
