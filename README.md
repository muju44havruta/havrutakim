# 세특 작성 도우미

학생이 수행한 결과물을 PDF로 업로드하거나 직접 입력한 자료를 바탕으로, Claude API를 이용해
과목별 세부능력 및 특기사항(세특) 문구 초안을 생성하는 Streamlit 앱입니다.

생성된 문구는 초안입니다. 반드시 교사가 사실관계와 내용을 검토·수정한 후 학교생활기록부에
반영하세요.

## 실행 방법

```bash
pip install -r requirements.txt

# Anthropic API 키를 환경변수로 설정 (또는 앱 실행 후 사이드바에서 직접 입력)
export ANTHROPIC_API_KEY="sk-ant-..."

streamlit run app.py
```

브라우저에서 `http://localhost:8501` 으로 접속하면 됩니다.

## 사용 흐름

1. **자료 입력**: 학생이 수행한 결과물의 PDF를 업로드해 텍스트를 추출하거나, 텍스트를 직접 입력합니다.
   두 방식을 함께 사용할 수 있습니다. (스캔본/이미지 PDF는 텍스트 추출이 되지 않을 수 있습니다.)
2. **학생 정보 및 옵션**: 학생 이름, 과목, 글자수, 문체 등을 선택합니다.
3. **세특 생성**: Claude API를 호출해 세특 문구 초안을 생성합니다.
4. **검토 및 저장**: 생성된 문구를 직접 수정한 뒤 기록으로 저장하거나 텍스트 파일로 다운로드합니다.

저장된 기록은 `data/records.json`에 로컬로 저장되며, '저장된 기록' 메뉴에서 학생별로 조회·수정·삭제할
수 있습니다.

## 기재 금지어 자동 점검

`관찰에서_세특까지.html`과 Streamlit 앱 모두, 세특 문구에 학교생활기록부 기재요령상 쓸 수 없는 내용과
관련된 표현이 있으면 경고를 띄웁니다. HTML 도구에서는 초안 속 해당 표현도 강조 표시합니다.

| 범주 | 수준 | 예시 키워드 |
|---|---|---|
| 대회·수상 | 금지 | 대회, 경시, 공모전, 수상, 입상, 최우수상, 1위 |
| 교외 온라인 강의 | 금지 | K-MOOC, MOOC, KOCW |
| 공인어학시험 | 금지 | TOEIC, TOEFL, TEPS, HSK, JLPT |
| 교외 인증시험·검정 | 금지 | 한국사능력검정, 한자능력검정 |
| 논문·출판·지식재산권 | 금지 | 학회, 학술지, 등재, 투고, 출간, 특허 |
| 해외 활동 | 금지 | 어학연수, 해외 봉사, 교환학생 |
| 부모·가정 배경 | 금지 | 부모님의 직업, 장학금 |
| 사교육 유발 요인 | 주의 | 학원, 과외, 인강, 컨설팅 |
| 특정 대학·기관명 | 주의 | ○○대학교, 수료 |

- 규칙은 `utils/forbidden_check.py`의 `RULES`와 HTML 안의 `FORBIDDEN_RULES`에 같은 내용으로 들어 있습니다.
  한쪽을 고치면 다른 쪽도 함께 고치세요.
- Claude API로 생성할 때도 프롬프트에 금지 사항을 넣어, 처음부터 해당 내용을 빼도록 지시합니다.
- 키워드 일치 방식이라 오탐·누락이 있을 수 있습니다. 최종 판단은 해당 학년도
  [학교생활기록부 기재요령](https://star.moe.go.kr/web/contents/m21100.do) 원문과 학교 학업성적관리위원회 기준을 따르세요.

## 과목별 과세특 예시 문구

2022 개정 교육과정 국어과 과목 8개에 대해 과세특 예시 문구 19개를 넣었습니다
(`utils/examples.py`의 `EXAMPLES`, HTML 안의 `SUBJECT_EXAMPLES`에 같은 내용으로 들어 있습니다).

| 과목 | 예시 |
|---|---|
| 공통국어 | 비평적 읽기, 갈등 조정 대화, 국어 규범 탐구 |
| 문학 | 시 감상(윤동주), 소설 서술 방식(한강), 다시 쓰기(현진건) |
| 독서와 작문 | 정보 글 요약, 논증하는 글 고쳐쓰기 |
| 화법과 언어 | 청중을 고려한 발표, 신조어 탐구 |
| 독서 토론과 글쓰기 | 독서 토론(샌델), 하브루타 질문 만들기(조세희), 관점 비교 논술 |
| 주제 탐구 독서 | 주제 통합 독서, 독서 성찰 |
| 문학과 영상 | 원작과 영상 비교, 시 영상 콘티 창작(김소월) |
| 매체 의사소통 | 뉴스 비판적 수용, 디지털 소통 윤리 |

- 모든 예시는 '수업 맥락 → 구체적 행동 → 드러난 역량 → 변화·성장' 구조를 따르며, 기재 금지어 점검을 통과합니다.
- **HTML 도구**: 학생 카드의 '과목별 예시 문구'를 펼치면 카드 과목에 맞는 예시가 나오고, 복사할 수 있습니다.
- **Streamlit 앱**: 과목을 고르면 예시가 나옵니다. '예시 문구의 서술 구조를 참고해서 생성하기'를 켜면
  Claude가 예시의 내용은 빼고 구조와 문체만 참고해 작성합니다.
- 가상의 학생을 상정한 예시입니다. 그대로 옮겨 쓰지 말고 실제 관찰한 활동에 맞게 고쳐 쓰세요.

## 좋은 과세특의 구조 (4단계)

> ① 수업 맥락(성취기준과 활동) → ② 학생의 구체적 행동(무엇을, 어떻게) → ③ 드러난 역량(교사의 평가 판단) → ④ 변화·성장(이전과 비교하거나 후속 탐구)

- **HTML 도구**
  - 상단의 '좋은 과세특의 구조 (4단계)' 안내 상자에서 단계 설명과 상투적 문장·4단계 문장 비교를 볼 수 있습니다.
  - 학생 카드의 활동 칸이 ①~④ 네 칸으로 되어 있고, 초안이 이 순서로 조립됩니다.
    ('~함', '~보임'처럼 이미 끝맺은 문장에는 '을(를) 수행함' 같은 어미를 덧붙이지 않습니다.)
  - 초안 아래에 4단계 충족 여부가 표시되고, 빠진 단계와 채우는 방법을 알려 줍니다. CSV에도 '구조(4단계 중)' 열이 추가됩니다.
  - 이전 버전에서 저장한 데이터는 그대로 불러오며, ④ 변화·성장 칸만 비어 있는 상태로 열립니다.
- **Streamlit 앱**
  - '좋은 과세특의 구조' 안내와 '4단계 입력 틀 넣기' 버튼으로 자료를 단계별로 정리해 입력할 수 있습니다.
  - Claude에 4단계 흐름으로 쓰되, 자료에 근거가 없는 단계는 지어내지 말고 생략하도록 지시합니다.

## 동료 교사 공유용 파일

`관찰에서_세특까지_공유용.html`은 동료 교사에게 나눠 주기 위한 빈 배포본입니다.

- HTML 파일에는 원래 학생 기록이 들어가지 않습니다. 기록은 각자의 브라우저 저장 공간에 따로 저장됩니다.
- 공유용 파일은 원본과 **다른 저장 공간 이름**을 씁니다. 그래서 교무실 공용 PC처럼 같은 컴퓨터·같은 브라우저에서 열어도
  원본 파일에 입력한 기록을 불러오지 않습니다.
- 기능은 원본과 같습니다. 원본을 고치면 공유용 파일도 다시 만들어야 합니다
  (`STORAGE_KEY`, `OLD_STORAGE_KEY`와 머리말의 '공유용 배포본' 표시만 다릅니다).

## 동료 교사 공유 안내서

`관찰에서_세특까지_동료교사_공유안내서.docx`는 동료 교사에게 도구를 나눠 줄 때 함께 보내는 4쪽짜리 안내서입니다.

- 함께 나누는 자료 목록(공유용 HTML, 사용 설명서, 세특 작성 도우미 앱)
- 학생 개인정보 주의사항: 앱은 입력 자료와 '학년/반/번호'를 Claude API로 보냄
- HTML 도구 빠른 시작, 앱 설치·실행 방법, 두 도구 비교
- 함께 보낼 메시지 예시와 참고 링크
