# 국어 구술 수행평가 도우미 (교실 PC용)

말로 묻고 답하는 소크라테스식 구술 수행평가 프로그램입니다.
학생의 **음성을 녹음해 보관**하고, 녹음을 **글로 옮긴 뒤(전사)**, **Claude가 잠정 평가와 피드백**을 작성합니다. 이를 바탕으로 **교사가 최종 점수와 피드백을 확정**합니다.

```
[수행 연습]  1 1차 구술 → 2 AI 평가·1차 피드백 → 3 수정 구술 → 4 AI 수정 평가 → 5 AI 2차 피드백
[실전 평가]  6 최종 구술(2차 피드백 반영) → 7 AI 평가·피드백 → 교사 최종 피드백(공개) → 이의제기·답변
```

교사 화면의 **진행 모드 탭**에서 「수행 연습(1~5단계)」, 「실전 수행평가(6~7단계)」, 「마감」을 고르면 학생 화면에 바로 반영됩니다.

---

## 1. 실행하기

### Windows 교실 PC (권장)
1. 받은 ZIP의 압축을 원하는 곳(예: `D:\구술평가`)에 풉니다. *바탕화면이나 USB도 됩니다.*
2. **`start-windows.bat`를 더블클릭**합니다.
   - 완전판에는 `runtime\node.exe`가 들어 있어 **따로 설치할 것이 없습니다.**
   - 처음 실행하면 Windows 방화벽 창이 뜹니다. **[개인 네트워크]에 체크하고 [허용]**을 누르세요. 그래야 학생 기기가 접속할 수 있습니다.
3. 교사 화면(`http://localhost:3000/teacher.html`)이 자동으로 열립니다.
4. 검은 창은 수업이 끝날 때까지 **닫지 마세요**. 창을 닫으면 프로그램이 꺼집니다.

### macOS
Node.js(LTS)를 설치한 뒤 `start-mac.command`를 더블클릭합니다. 처음 한 번은 **우클릭 → 열기**로 실행해야 합니다.

## 2. 처음 설정 (5분)
1. **교사 비밀번호 정하기**: 8자 이상. 이 설정은 교사 PC에서만 할 수 있습니다.
2. **Claude API 키 입력**: [Anthropic 콘솔](https://console.anthropic.com)에서 키를 발급받아 **설정 ▸ ① Claude**에 붙여 넣고 **[Claude 연결 확인]**을 누릅니다.
   - 평가 모델은 기본값 **Claude Opus 5.5**(가장 정확)를 권장합니다. 비용을 줄이려면 Sonnet 5.5를 고르세요.
   - 키는 교사 PC의 `data/config.json`에만 저장되며 학생에게 전달되지 않습니다.
3. **전사 방식 선택**: 아래 표를 참고하세요.
4. 실제 수업 전에는 **모의 AI 모드**를 켜고 화면 흐름을 먼저 연습해 보세요(API 키 불필요). 실제 수업 전에는 반드시 끄세요.

| 전사 방식 | 비용 | 장점 | 주의 |
|---|---|---|---|
| **브라우저 음성 인식**(기본) | 무료 | 말하는 동안 바로 글로 바뀜 | 크롬·엣지·삼성 인터넷·사파리가 필요합니다. 일부 안드로이드 폰은 녹음과 인식이 동시에 되지 않을 수 있습니다. |
| **OpenAI 음성 인식** | 녹음 1분당 약 4~9원 | 저장된 녹음 파일로 전사해 정확도가 높고 기기 영향이 적음 | OpenAI 키가 별도로 필요합니다(평가는 계속 Claude가 합니다). |

> Claude는 **텍스트**를 평가합니다. 따라서 음성을 글로 옮기는 단계가 따로 있습니다.
> 인식이 틀린 부분은 교사가 녹음을 들으며 **전사문을 고친 뒤 [저장 후 AI 재평가]**를 누르면 됩니다. 수정한 이력은 모두 남습니다.

## 3. 수업 진행
1. **새 수업 만들기**: 영역(시·소설·비문학·토론·자유)을 고르면 구술 과제와 평가 기준이 자동으로 채워집니다. 필요하면 고칩니다.
   - 평가 기준 형식은 `기준명 | 배점 | 상·중·하 설명 | 교사`입니다. 끝에 `교사`라고 적은 기준(예: 목소리·태도 같은 전달력)은 AI가 채점하지 않고 교사가 녹음을 듣고 채점합니다.
   - 성취기준 칸에 학교 교육과정의 성취기준을 붙여 넣으면 AI가 평가 관점으로 참고합니다.
2. **학생 접속(QR)** 탭에서 QR코드를 띄웁니다. 학생은 **같은 와이파이**에서 QR을 찍습니다.
   - 처음에 "연결이 비공개로 설정되어 있지 않습니다" 경고가 나옵니다. **고급 → 이동**을 누르면 됩니다(아이폰은 세부사항 보기 → 이 웹 사이트 방문). 교사 PC가 직접 만든 보안 인증서라서 나오는 경고입니다. 학생 기기에서 마이크를 쓰려면 이런 보안 연결(HTTPS)이 꼭 필요합니다.
   - 학생은 실명 대신 **식별명(예: 2-3-07)과 PIN 4자리**로 입장합니다. 다음 시간에 같은 식별명과 PIN으로 다시 들어오면 기록이 이어집니다.
3. **수행 연습(1~5단계)**: 학생이 1차 구술을 녹음해 제출하면 AI가 1차 피드백과 생각해 볼 질문을 줍니다. 학생이 이를 반영해 수정 구술을 하면 AI가 비교 평가와 2차 피드백을 줍니다. 연습 단계에서는 제출 전까지 몇 번이든 다시 녹음할 수 있습니다.
4. **실전 수행평가(6~7단계)**: 진행 모드를 「실전 수행평가」로 바꾸면 학생 화면이 최종 구술 단계로 넘어갑니다.
   - 녹음 기회는 수업 설정에서 정한 횟수(기본 1회)만큼이며, **서버가 녹음 시작 횟수를 직접 셉니다.**
   - 녹음 중 다른 화면으로 나간 횟수가 기록되어 교사에게 보입니다.
   - 실전 AI 평가는 기본적으로 **교사가 최종 결과를 공개할 때까지 학생에게 보이지 않습니다.**
5. **교사 최종 평가**: 학생을 누르면 녹음, 전사문, AI 평가가 모두 보입니다. 확정 점수 칸에는 AI 점수가 미리 채워져 있으니 녹음을 들으며 확인·수정하고, 최종 피드백을 다듬습니다. **[저장하고 학생에게 공개]**를 누르면 학생에게 보입니다.
   - **세특 작성 참고 문장**도 함께 나오지만 학생에게는 보이지 않습니다. 교사 관찰을 바탕으로 반드시 검토·수정하세요.
6. **이의제기**: 결과 공개 후 학생이 이의를 제기하면 교사 화면에 표시됩니다. 녹음 원본을 다시 듣고 답변하고, 필요하면 점수를 고쳐 다시 공개합니다.
7. **재응시**: 기기 고장 등으로 녹음을 다시 받아야 하면 [이 단계부터 다시 녹음하게 하기]를 누릅니다. 이전 녹음과 평가는 **삭제되지 않고 보관함으로 옮겨집니다.**

## 4. 증빙과 이의제기 대응
- **녹음 원본**은 `data/audio/수업코드/식별명_단계_날짜.webm` 파일로 저장됩니다.
- 각 녹음의 **SHA-256 지문**을 제출 시점에 기록해 둡니다. 나중에 파일이 바뀌지 않았음을 확인할 수 있습니다(Windows: `certutil -hashfile 파일명 SHA256`).
- **기록 보고서(인쇄·PDF)**: 학생별로 과제, 평가 기준, 단계별 전사문, AI 평가, 교사 최종 평가, 이의제기, 활동 기록(제출·재평가·공개 시각)을 한 문서로 출력합니다.
- **내보내기**: 성적과 피드백은 엑셀에서 바로 열리는 CSV로, 전체 기록은 JSON으로 백업할 수 있습니다.
- 보관 기간이 끝나면 **내보내기·보관 ▸ 이 수업과 모든 녹음 삭제**로 지웁니다.

## 5. 학생 기기가 접속되지 않을 때
| 증상 | 해결 |
|---|---|
| QR을 찍어도 페이지가 안 열림 | 교사 PC와 학생 기기가 같은 와이파이인지 확인합니다. 방화벽에서 Node.js의 '개인 네트워크'를 허용했는지 확인합니다. 교사 PC 주소 목록에서 다른 주소를 골라 봅니다. |
| 학교 와이파이가 기기끼리의 통신을 막음 | **교사 PC 한 대로 진행**합니다. 교사 PC에서 `http://localhost:3000/student.html`을 열고 학생이 차례로 나와 녹음합니다. 헤드셋 마이크를 권장합니다. |
| "마이크를 쓸 수 없어요" | `https://` 주소로 접속했는지 확인하고, 주소창 자물쇠 아이콘에서 마이크를 '허용'으로 바꿉니다. |
| 음성 인식 결과가 비어 있음 | 녹음은 저장되어 있습니다. 교사가 녹음을 듣고 전사문을 입력하면 평가가 진행됩니다. 휴대폰이 많다면 OpenAI 음성 인식을 권장합니다. |

## 6. 꼭 지켜 주세요
- **AI 점수는 잠정 평가입니다.** 최종 성적은 교사가 녹음을 확인하고 확정합니다. AI 평가의 신뢰도는 학교에서 시범 운영하며 교사 채점과 비교해 점검하세요.
- 학생 전사문과 제시문은 평가를 위해 **Anthropic(Claude)**으로, OpenAI 음성 인식을 쓰면 녹음이 **OpenAI**로 전송됩니다. 이 두 회사는 해외 사업자입니다. 운영 전에 학교의 개인정보 처리 절차(동의, 외부 서비스 이용 승인)를 확인하세요. 학생 실명·학번은 쓰지 마세요.
- `data` 폴더에는 API 키와 학생 녹음이 들어 있습니다. 외부에 공유하거나 클라우드에 올리지 마세요.
- 제시문으로 수능 기출이나 교과서 작품을 쓸 때는 저작권 이용 범위를 확인하세요.

## 7. 비용 예상
구술 1건 평가에는 입력 약 3천~6천 토큰, 출력(분석 포함) 약 2천~5천 토큰이 듭니다. Claude Opus 5.5(입력 100만 토큰당 4달러, 출력 20달러) 기준으로 **1건에 약 0.05~0.12달러(70~170원)**입니다. 학생 30명 × 3회(90건)면 **대략 1만 원 안팎**입니다. Sonnet 5.5를 쓰면 약 절반입니다. 실제 비용은 제시문과 답변 길이에 따라 달라지므로, [Anthropic 콘솔](https://console.anthropic.com)에서 **월 사용 한도**를 꼭 설정하세요.

## 8. 기술 정보
- Node.js 20 이상, 외부 의존성 4개(`@anthropic-ai/sdk`, `zod`, `qrcode`, `selfsigned`)
- 교사용 `http://localhost:3000`(이 PC에서만 접속 가능), 학생용 `https://(교사PC IP):3443`(자체 서명 인증서)
- 데이터: `data/db.json`(기록), `data/config.json`(설정·비밀번호 해시·API 키), `data/audio/`(녹음)
- 교사 비밀번호는 scrypt 해시로 저장하고, 5회 틀리면 1분간 잠깁니다. 접속 토큰은 서명 방식이라 PC를 껐다 켜도 이어집니다.
- AI 처리는 동시에 3건씩 대기열로 처리합니다. 서버가 꺼졌다 켜지면 처리 중이던 항목을 이어서 처리합니다.
- 평가는 정해진 형식의 응답(structured outputs)으로 받습니다. 서버가 점수를 배점 범위로 제한하고 합계를 직접 계산합니다. Claude가 응답을 거절하면 서버 쪽 대체 모델(`fallbacks: "default"`)로 자동으로 다시 시도합니다.
