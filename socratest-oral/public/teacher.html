수업 코드

  1. 학생은 휴대폰·태블릿·크롬북으로 QR코드를 찍거나 주소를 입력합니다.
  2. 처음 한 번 "연결이 비공개로 설정되어 있지 않습니다" 경고가 나옵니다. 교사 PC가 직접 만든 인증서이기 때문이며, 고급 → (주소)로 이동을 누르면 됩니다. (아이폰: 세부사항 보기 → 이 웹 사이트 방문)
  3. 식별명(예: 2-3-07)과 PIN 4자리를 정해 입장하고, 마이크 사용을 허용합니다.
  4. 학생 기기가 접속되지 않으면: 교사 PC와 같은 와이파이인지, Windows 방화벽에서 Node.js를 '개인 네트워크' 허용했는지 확인하세요. 학교 와이파이가 기기 간 통신을 막는 경우 교사 PC 한 대에서 학생이 차례로 녹음하는 방식(이 PC 주소: http://localhost:3000/student.html)을 쓰세요.

학생 실명·학번 대신 식별명을 쓰게 하세요. 녹음 파일은 이 PC의 data 폴더에만 저장됩니다.

메일 제출 · 학생이 자기 폰으로 영상을 녹화해 선생님 메일로 보내기

학생은 휴대폰에서 학생용 HTML(또는 웹 링크)을 열어 얼굴이 보이게 영상으로 녹화하고, [메일 쓰기]로 선생님 메일에 영상을 첨부해 보냅니다. 선생님은 메일에서 영상 파일을 내려받아 아래에서 한꺼번에 가져오면 영상이 보관되고, 글로 변환된 뒤 AI 평가가 진행됩니다.

제출 받을 메일 주소는 「수업 설정 편집」에서 등록합니다. 현재:

  1. 제시문·과제·평가 기준이 들어 있습니다.
  2. 학생에게 나눠 주기
    • 권장: 웹 링크로 나눠 주기. GitHub Pages의 교사용 화면에서 만든 링크·QR을 쓰면 학생이 화면에서 바로 녹화합니다(영상 크기를 3분 ≈ 10MB로 줄여 메일 첨부가 쉬움).
    • 파일로 나눠 주기. 학생이 휴대폰에서 파일을 열면 브라우저에 따라 화면 녹화가 막힐 수 있습니다. 그럴 때는 휴대폰 카메라 앱으로 찍어 첨부하는 방식이 되며, 파일이 커서 메일 전송이 어려울 수 있습니다.
  3. 메일로 받은 영상 가져오기: 파일 이름(oral_코드_식별명_s단계_…)에서 학생과 단계를 자동으로 읽습니다.

메일 제출에는 실전 녹화 횟수 제한이 적용되지 않습니다(학생이 여러 번 찍고 하나를 보낼 수 있음). 화면 녹화가 아니라 카메라 앱으로 찍어 낸 영상, 녹화 중 화면 이탈 횟수는 학생 상세 화면에 표시됩니다. 피드백은 [학생에게 보낼 피드백 복사]로 메일 답장·클래스룸에 붙여 넣어 전달하세요. 학생 얼굴이 담긴 영상은 민감한 개인정보이므로 평가가 끝나면 학교 기준에 따라 삭제하세요.

내보내기·보관

녹음 원본은 교사 PC의 폴더 안 audio/에 "식별명_단계_날짜" 이름으로 저장되어 있습니다. 각 녹음의 SHA-256 값(지문)이 기록되어 있어, 나중에 파일이 바뀌지 않았음을 확인할 수 있습니다.

보관 기간이 끝나면 아래에서 수업 전체(녹음 포함)를 삭제하세요. 학교의 수행평가 증빙 보관 기준을 따르세요.
