수업 코드

  1. 학생은 휴대폰·태블릿·크롬북으로 QR코드를 찍거나 주소를 입력합니다.
  2. 처음 한 번 "연결이 비공개로 설정되어 있지 않습니다" 경고가 나옵니다. 교사 PC가 직접 만든 인증서이기 때문이며, 고급 → (주소)로 이동을 누르면 됩니다. (아이폰: 세부사항 보기 → 이 웹 사이트 방문)
  3. 식별명(예: 2-3-07)과 PIN 4자리를 정해 입장하고, 마이크 사용을 허용합니다.
  4. 학생 기기가 접속되지 않으면: 교사 PC와 같은 와이파이인지, Windows 방화벽에서 Node.js를 '개인 네트워크' 허용했는지 확인하세요. 학교 와이파이가 기기 간 통신을 막는 경우 교사 PC 한 대에서 학생이 차례로 녹음하는 방식(이 PC 주소: http://localhost:3000/student.html)을 쓰세요.

학생 실명·학번 대신 식별명을 쓰게 하세요. 녹음 파일은 이 PC의 data 폴더에만 저장됩니다.

독립형 HTML · 서버 없이 녹음 제출받기

학교 와이파이에서 학생 기기가 교사 PC에 접속되지 않을 때 씁니다. 학생은 휴대폰에서 이 HTML로 녹음하고, 만들어진 제출 파일(.json)을 클래스룸·과제함 등으로 보냅니다. 교사가 그 파일들을 아래에서 가져오면 녹음이 저장되고 AI 평가가 진행됩니다.

  1. 제시문·과제·평가 기준이 들어 있습니다.
  2. 학생에게 나눠 주기
    • 권장: 인터넷 주소로 올리기. GitHub Pages나 Netlify Drop처럼 https 주소를 주는 곳에 올리면, 학생이 링크를 열어 화면에서 바로 녹음할 수 있습니다(말하는 동안 글자 변환 포함).
    • 파일로 나눠 주기. 학생이 휴대폰에서 파일을 열면 브라우저에 따라 화면 녹음이 막힐 수 있습니다. 그럴 때는 휴대폰 기본 녹음기로 녹음해 첨부하는 방식으로 자동 전환됩니다.
  3. 학생 제출 파일 가져오기:

독립형 제출에는 실전 녹음 횟수 제한이 적용되지 않습니다. '녹음 파일 첨부'로 낸 녹음은 학생 상세 화면에 표시되니, 실전 평가는 가능하면 교실에서 교사 PC 접속 방식으로 진행하세요. 독립형으로 낸 학생에게는 교사가 [피드백 복사]로 AI 피드백을 전달하거나, 학생이 나중에 같은 식별명으로 교사 PC에 접속해(처음 정하는 PIN으로) 볼 수 있습니다.

내보내기·보관

녹음 원본은 교사 PC의 폴더 안 audio/에 "식별명_단계_날짜" 이름으로 저장되어 있습니다. 각 녹음의 SHA-256 값(지문)이 기록되어 있어, 나중에 파일이 바뀌지 않았음을 확인할 수 있습니다.
