# 2027학년도 수능 대비 국어 영역 모의평가 (1교시 전체: 공통 + 화법과 작문)

| 회차 | 난이도 | 문제지(B4, 2단) | 정답과 해설 |
|---|---|---|---|
| 제1회 | 하 | `제1회_하_국어_문제지_B4.pdf` | `제1회_하_국어_정답과해설.pdf` / `.docx` |
| 제2회 | 중 | 저장소 밖에서 직접 전달(아래 참고) | 저장소 밖에서 직접 전달 |
| 제3회 | 상 | (예정) | (예정) |

- 구성은 2027학년도 6월 모의평가를 따랐습니다(1~3 독서 이론, 4~9 인문 (가)·(나), 10~13 사회, 14~17 과학, 18~21 현대 소설, 22~27 현대시·수필, 28~31 고전 소설, 32~34 고전 시가, 35~45 화법과 작문).
- 독서 지문과 화법과 작문 지문은 새로 썼습니다. 문학은 EBS 『2027 수능특강 국어영역 문학』에 실린 작품 가운데 저작권 보호 기간이 끝난 작품만 골라, 문항을 새로 만들었습니다.
- `src/*.exam.txt`가 문제지 원본입니다. `tools/build_exam.py`가 이를 B4 2단 HTML로 바꾸고, Chromium으로 PDF를 만듭니다. 글꼴은 나눔명조·나눔고딕(`npm pack @fontsource/nanum-myeongjo @fontsource/nanum-gothic`)을 HTML 옆 `fonts/`에 두고 씁니다.

## 저작권 보호 작품을 쓴 회차

이 저장소는 공개(public) 저장소입니다. 제2회부터는 저작권 보호 기간이 남은 문학 작품(박태원, 김광균, 김용준 등)을 교육 목적으로 활용했습니다. 그래서 문제지와 해설은 저장소에 올리지 않고 사용자에게 직접 전달했습니다(저작권법 제25조 학교 교육 목적 이용, 제32조 시험 문제로서의 복제 범위). 저장소에는 새로 쓴 독서 지문 원본(`src/2회_중_독서.exam.txt`)만 둡니다.
