# 뱃살 빼기 체크리스트

50대 남성 뱃살 빼기 프로젝트용 식단·생활 루틴 체크리스트 앱입니다. 별도 설치나 서버 없이
브라우저에서 `index.html`만 열면 바로 사용할 수 있습니다.

## 실행 방법

`index.html` 파일을 더블클릭하거나 브라우저 주소창에 파일 경로를 입력해서 엽니다.
GitHub Pages 등 정적 호스팅에 올려서 휴대폰에서 접속해도 됩니다.

```bash
# 로컬에서 간단히 띄우고 싶다면
cd belly-fat-checklist
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 기능

- **요일 탭**: 월~일 요일을 선택하면 해당 요일의 식단(아침/점심/저녁)·생활 루틴이 표시됩니다.
  평일 점심은 급식으로 고정되어 있습니다.
- **날짜 이동**: 이전/다음 날 버튼이나 날짜 선택으로 과거·미래 날짜를 확인·기록할 수 있습니다.
  같은 요일이면 같은 체크리스트 구성을 보여주되, 체크 상태는 날짜별로 따로 저장됩니다.
- **오늘의 달성률**: 체크한 항목 수를 기준으로 진행률이 실시간으로 표시됩니다.
- **수분 섭취 체크**: 물 한 컵(약 250ml) 단위로 8칸을 체크해 하루 1.5~2L 목표를 추적합니다.
- **공통 원칙 체크**: 정제 탄수화물 줄이기, 채소 매끼 2줌, 먹는 순서, 야식·과식·술 줄이기 4가지
  원칙을 매일 체크합니다.
- **체중·허리둘레 기록**: 날짜별로 체중(kg)·허리둘레(cm)를 입력해 저장하고 최근 기록을 표로
  확인할 수 있습니다 (토요일 21:00 측정 권장).
- **최근 7일 달성률**: 최근 7일간의 하루 달성률을 막대그래프로 한눈에 볼 수 있습니다.
- **초기화**: 특정 날짜의 체크 기록만 따로 초기화할 수 있습니다.

## 데이터 저장

모든 체크 상태와 체중 기록은 브라우저의 `localStorage`에만 저장됩니다. 서버로 전송되지
않으며, 브라우저 저장소를 지우거나 다른 기기·브라우저에서 열면 기록이 보이지 않습니다.

## 커스터마이즈

식단·루틴 내용은 `index.html` 상단 스크립트의 `DIET`, `ROUTINE`, `RULES` 객체를 수정해서
자유롭게 바꿀 수 있습니다.
